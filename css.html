УРОК 02 ИЗ 03 · CSS

Оформление и сетка

Цвета, отступы, Flexbox, Grid и узкие экраны.

Стили превращают разметку в интерфейс

CSS задаёт внешний вид HTML-элементов. Селектор выбирает элементы, а свойства определяют цвет, размеры и расположение. Подключи отдельный файл через <link rel="stylesheet" href="style.css"> в head.

Селектор
Указывает, к каким элементам применяется правило.
margin и padding
Внешний и внутренний отступы.
Flexbox
Удобен для строки навигации и выравнивания.
Grid
Удобен для сетки карточек.
Медиазапрос
Меняет оформление при заданном условии, например ширине экрана.

Пример кода

/* Правило для всех элементов, включая рамки и отступы. */
* { box-sizing: border-box; }
body { margin: 0; font-family: Arial, sans-serif; }
main { max-width: 960px; margin: auto; padding: 24px; }
.cards {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 20px;
}
img { max-width: 100%; height: auto; }
@media (max-width: 700px) {
  .cards { grid-template-columns: 1fr; }
}

Класс cards назначается контейнеру с тремя дочерними блоками. На широком экране они стоят в ряд, а на узком — друг под другом.

ПРАКТИКА ПО ТЕМЕ

Оформи три карточки

Создай три блока в контейнере с классом cards. Добавь им padding, фон и рамку. Проверь страницу при ширине 375 и 1280 пикселей.

Показать подсказку

Для класса используется точка: .cards. Чтобы отступы не расширяли заданную ширину, пригодится box-sizing: border-box.

Критерии самопроверки

  • CSS подключён отдельным файлом.
  • На широком экране видны три колонки.
  • На узком экране карточки стоят в одну колонку.
  • Основной текст не требует горизонтальной прокрутки.

Проверяй результат в своём браузере. Сайт не оценивает твой код автоматически.
