УРОК 01 ИЗ 03 · HTML

Структура страницы

Заголовки, абзацы, списки и смысловые блоки.

Разметка задаёт смысл

HTML описывает содержание страницы. Заголовок обозначают тегом h1, абзац — p, ссылку — a. Семантические элементы помогают понять назначение блоков. Это полезно и людям, и вспомогательным программам.

header
Вводная часть страницы или раздела.
nav
Основные навигационные ссылки.
main
Главное содержание страницы.
section
Тематический раздел, обычно с заголовком.
footer
Заключительная информация.

Пример кода

<!doctype html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Моё увлечение</title>
</head>
<body>
  <header><h1>Моё увлечение — волейбол</h1></header>
  <main>
    <p>Мне нравится играть в команде.</p>
    <h2>Что нужно для игры</h2>
    <ul><li>Мяч</li><li>Спортивная обувь</li></ul>
  </main>
  <footer>Моя первая страница</footer>
</body>
</html>

Сохрани этот пример в index.html и открой файл в браузере. Внешний вид пока простой: оформление добавляется отдельно.

ПРАКТИКА ПО ТЕМЕ

Страница об увлечении

Сделай заголовок, абзац, список из трёх пунктов и ссылку на полезный ресурс. Добавь своё изображение с описанием alt.

Показать подсказку

Начни с образца выше. Изображение подключается так: <img src="images/photo.jpg" alt="Описание фотографии">. Файл должен находиться по указанному пути.

Критерии самопроверки

  • Есть один главный заголовок h1.
  • Список содержит минимум три пункта.
  • Ссылка открывает нужный ресурс, изображение загружается.
  • Используются header, main и footer.

Проверяй результат в своём браузере. Сайт не оценивает твой код автоматически.
