УРОК 03 ИЗ 03 · JavaScript

Первое действие

Находим элемент и реагируем на нажатие кнопки.

Событие запускает действие

JavaScript может изменять содержание страницы в ответ на действие пользователя. Найдём кнопку через querySelector и добавим обработчик события click. Для обычной кнопки click работает также при активации с клавиатуры.

const
Объявляет переменную, которой нельзя присвоить другое значение.
querySelector
Находит первый элемент по CSS-селектору.
addEventListener
Подключает обработчик события.
textContent
Читает или заменяет текст элемента.

Пример кода

<!-- Добавь эти элементы в body. -->
<button id="hello-button" type="button">Поздороваться</button>
<p id="hello-text" aria-live="polite">Нажми кнопку.</p>
<script>
  const button = document.querySelector('#hello-button');
  const text = document.querySelector('#hello-text');
  button.addEventListener('click', function () {
    text.textContent = 'Привет! JavaScript работает.';
  });
</script>

В примере script находится после элементов. Для отдельного файла в head используй defer, чтобы разметка была разобрана перед выполнением кода.

ПРАКТИКА ПО ТЕМЕ

Кнопка приветствия

Добавь кнопку и абзац. При нажатии меняй текст абзаца. Проверь действие мышью и клавиатурой.

Показать подсказку

Если кнопка не работает, проверь совпадение id в HTML и селектора в JavaScript. Открой консоль браузера и прочитай сообщение об ошибке.

Критерии самопроверки

  • Кнопка имеет понятную подпись.
  • Нажатие меняет текст без перезагрузки.
  • Кнопка доступна через Tab и срабатывает через Enter.
  • В консоли нет ошибок, связанных с этим кодом.

Проверяй результат в своём браузере. Сайт не оценивает твой код автоматически.
